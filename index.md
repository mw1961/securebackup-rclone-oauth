# SecureBackup-Rclone

SecureBackup-Rclone is a personal, non-commercial application used solely by its owner to access Google Drive for encrypted backup storage.

The application uses Rclone as the Google Drive transport layer. Backup data is encrypted locally by Restic before it is transferred to Google Drive.

The application is not offered as a service to other users and does not sell, share, or monetize user data.
